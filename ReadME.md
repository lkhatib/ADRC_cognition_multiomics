# Interconnected influences of diet, gut microbiome, and metabolome on cognition across three metabolomics platforms

This repository contains analysis scripts used to generate microbiome, metabolomics, diet, and cognition results for the manuscript:

**Interconnected influences of diet, gut microbiome, and metabolome on cognition across three metabolomics platforms**

The workflow integrates fecal shotgun metagenomic profiles, dietary variables, cognitive outcomes, and plasma metabolomics data measured across three platforms. The scripts are provided to document the analysis workflow and support reproducibility. Participant-level metadata and omics tables are not included in this repository because they may be subject to data-use agreements and participant privacy restrictions.

## Analysis workflow

1. **Calculate genome coverage summaries**  
   Run `scripts/1_calculating_coverages_micov.sh` on an HPC system with `micov` installed. This produces coverage summaries used for feature filtering.

2. **Filter low-coverage metagenomic features**  
   Run `notebooks/1_feature_filtering.ipynb` to remove genomes/features below the coverage threshold and write the filtered BIOM table.

3. **Merge and clean data layers**  
   Run `notebooks/2_merging_cleaning_data.ipynb` to match fecal metagenomics, plasma metabolomics, diet variables, and participant metadata.

4. **Generate demographics table**  
   Run `notebooks/3_demographics_table.ipynb` to summarize participant characteristics by cognitive status.

5. **Run exploratory correlations and generate figures**  
   Run `notebooks/4_exploratory_correlations.ipynb` to evaluate microbe-metabolite, microbe-cognition, diet-microbiome, and diet-metabolome associations.

6. **Run joint-RPCA integration**  
   Run `notebooks/5_joint_rpca.ipynb` to integrate multi-platform metabolomic and metagenomic features using joint robust principal component analysis.

## Input data

The notebooks expect approved, de-identified data files in `data/` and generated intermediate outputs in `output_files/`. File names in the notebooks reflect the analysis inputs used for the manuscript. If reproducing the analysis with a different data release, update the file paths and column names as needed.

Expected input categories include:

- Fecal shotgun metagenomic feature table in BIOM format
- micov coverage summary file
- Participant metadata and cognitive outcomes
- Dietary variables, including Healthy Eating Index components
- Plasma metabolomics tables by platform
- Taxonomy mapping file for metagenomic features

## Software requirements

Core Python packages are listed in `requirements.txt`. Some analyses additionally require QIIME 2, BIOM, scikit-bio, gemelli, and micov. The exact versions may depend on the compute environment used to process the source data.

## Reproducibility notes

- Notebook outputs were cleared before public release.
- Absolute local paths were replaced with relative paths where possible.
- Data files are not included and should not be committed unless they are approved for public release.
- Generated files in `figures/` and `output_files/` can be regenerated by running the workflow in order.
